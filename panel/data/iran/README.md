# منابع و پوشش داده

- استان، شهرستان، بخش، شهر و دهستان: https://github.com/sajaddp/list-of-cities-in-Iran ، داده برگرفته از فایل رسمی تقسیمات کشوری ۱۴۰۴. مجوز منبع همراه این پوشه است؛ کد ابزارهای آن مخزن استفاده نشده است.
- مختصات مرکز استان و شهرستان: GeoNames، CC BY 4.0؛ https://www.geonames.org/ . این نقاط مرکز اداری هستند، نه محل دقیق دفتر.
- محله/منطقه تهران: https://github.com/zarbinco/laravel-iran-locations و https://github.com/sadegh-khan/tehran-map-geojson . داده شهری با تقسیمات کشوری متفاوت است.
- محله‌های دارای شهر مشخص: OpenStreetMap contributors، ODbL؛ https://www.openstreetmap.org/copyright . نام شهر فقط از تگ صریح گرفته می‌شود؛ نسبت‌دادن محله با حدس نزدیک‌ترین شهر انجام نمی‌شود.
- تکمیل محله‌های شهرهای کشور در زمان انتخاب شهر: API عمومی places دیوار. اجازه نگهداری کپی داده در مستندات رسمی آمده است: https://github.com/divar-ir/rtb-docs/blob/main/rtb.md . شناسه شهر فقط از تطبیق نام شهر و استان انتخاب می‌شود.

پوشش تقسیمات کشوری سراسری است. هیچ منبع عمومی بررسی‌شده، تضمین پوشش صددرصد تمام محله‌ها و نسبت شهرداری آنها در سراسر ایران نمی‌دهد. محله بدون رابطه معتبر با منطقه، به منطقه‌ای حدسی منتسب نمی‌شود. داده پایه از سرور خود برنامه ارائه می‌شود؛ منابع بیرونی در صورت درخواست کاربر و با cache استفاده می‌شوند.
