# محیط نمایشی ایزوله و Seed

`seed_demo` فقط برای دیتابیس Demo مستقل روی سرور طراحی شده است. هیچ dump یا داده واقعی Production را در Demo کپی نکنید. تنظیمات Demo باید SECRET_KEY، کلید JWT، PostgreSQL، Redis/channel prefix، Media و دامنه مستقل داشته باشند. برای جلوگیری از برخورد کوکی‌ها، نام کوکی‌ها یا میزبان API Demo جدا باشند. دسترسی محیط نمایشی دارای رمز مشترک را به شبکه/کاربران آزمایش محدود کنید.

سه محافظ هم‌زمان لازم‌اند:

```python
MLKINO_DEMO_ENV = True
MLKINO_DEMO_SEED_ALLOWED = True
# DATABASES['default']['NAME'] باید شامل demo باشد؛ مثلاً mlkino_demo.
```

اجرای واقعی علاوه بر تنظیمات، نام دیتابیس متصل‌شده را با `current_database()` در PostgreSQL بررسی می‌کند؛ استفاده از database router رد می‌شود تا نوشتن به اتصال دیگری منحرف نشود. SQLite فقط در تست ایزوله و با mock بررسی اتصال استفاده می‌شود، نه اجرای واقعی Seed.

هیچ `--force` یا سوییچ دورزدن محافظ Production وجود ندارد. حتی `--dry-run` در محیط غیرمجاز رد می‌شود.

```sh
# فقط با تنظیمات و دیتابیس مستقل Demo روی سرور:
python manage.py migrate --settings=mlkino.demo
python manage.py seed_demo --settings=mlkino.demo --profile=full --dry-run
python manage.py seed_demo --settings=mlkino.demo --profile=full
```

نام ماژول `mlkino.demo` در این نمونه باید با ماژول واقعی محیط Demo که در استقرار تعریف می‌شود برابر باشد. این راهنما به‌تنهایی ادعای ایجاد یا استقرار چنین محیطی نیست.

رمز پیش‌فرض تمام حساب‌های ایجادشده طبق درخواست مالک `123456789` است. دستور از نام‌فضای `MLKINO-DEMO-v1` و شناسه‌های تکرارپذیر استفاده می‌کند؛ داده کاربران واقعی را حذف، flush یا بازنویسی نمی‌کند. اگر شماره رزروشده با حسابی خارج از نام‌فضای Demo تداخل داشته باشد، کل تراکنش رد می‌شود. اجرای مجدد رکوردها را تکراری نمی‌کند و اسناد ثبت‌شده قبلی را تغییر نمی‌دهد. فقط رمز حساب‌های متعلق به همین Seed به رمز مشخص‌شده برگردانده می‌شود.

پروفایل `full`: سوپرادمین، ۵ دفتر با توزیع کارشناسان صفر/۳/۴/۵، بازار املاک مرجع، ۱۲ کارشناس، ۱۲ کاربر با نقش‌های مالک/خریدار/موجر/مستأجر، ۴۰ فایل/درخواست با جغرافیا و بازه زمانی متنوع، وضعیت انتشار، تصاویر نمایشی، ارجاع و تاریخچه، علاقه‌مندی، گفتگو، پیشنهاد، بازدید، قرارداد، پیگیری، اعلان، یادآوری، وظیفه و سند مالی متوازن ایجاد می‌کند. پروفایل `small` مجموعه محدودتری برای Smoke Test است. تصویر پروانه با برچسب صریح DEMO تولید می‌شود و شماره‌ها، هویت‌ها و اسناد هیچ اعتبار واقعی ندارند؛ احراز هویت تأییدشده جعل نمی‌شود.

زمان مبنای Seed در تنظیمات همان Demo نگه‌داری می‌شود تا اجرای دوباره، slot و rate تکراری نسازد. Seed هیچ SMS، ایمیل یا درخواست جیبیت ارسال نمی‌کند. اعلان‌ها صرفاً داخل دیتابیس Demo هستند. خروجی فقط نقش‌ها، شماره‌های نمایشی و تعدادها را نمایش می‌دهد؛ رمز و توکن در خروجی چاپ نمی‌شوند.

تست‌های Seed فقط در دیتابیس موقت Django اجرا می‌شوند و با دیتابیس لوکال برنامه فرق دارند. برای اجرای واقعی باید استقرار، نام دیتابیس و guardها روی سرور بررسی شده باشند. بدون مشاهده نتیجه واقعی Seed، وضعیت آن Completed اعلام نشود.

## طرح اجرای مستقل آماده‌شده

ماژول واقعی `mlkino.demo` از تنظیمات Production import نمی‌کند. دیتابیس و کلید امضای آن مستقل‌اند؛ prefix نام DB باید `mlkino_demo_` باشد. API روی `127.0.0.1:8102`، پنل روی `127.0.0.1:4200` و لندینگ روی `127.0.0.1:4201` اجرا می‌شوند. دسترسی مرورگر با SSH port-forward و نام `demo.localhost` خواهد بود تا کوکی Demo حتی با توسعه لوکال روی localhost تداخل نداشته باشد. این پیش‌نمایش HTTP فقط روی loopback و داخل تونل رمزگذاری‌شده SSH است، نه سرویس HTTP عمومی.

برای نصب، env خصوصی سرور باید `MLKINO_DEMO_SECRET_KEY`, `MLKINO_DEMO_DB_NAME`, `MLKINO_DEMO_DB_USER`, `MLKINO_DEMO_DB_PASSWORD`, `MLKINO_DEMO_MEDIA_ROOT` داشته باشد. API به‌طور صریح پیامک و استعلام هویت/کدپستی واقعی را مسدود می‌کند. فایل‌های خصوصی از مسیر عمومی media قابل دریافت نیستند.

Build پنل با `REACT_APP_API_URL=http://demo.localhost:8102`, `REACT_APP_WS_URL=ws://demo.localhost:8102`, `REACT_APP_LANDING_URL=http://demo.localhost:4201` ساخته می‌شود. لندینگ با `NEXT_PUBLIC_API_URL=http://demo.localhost:8102`, `NEXT_PUBLIC_PANEL_URL=http://demo.localhost:4200` ساخته می‌شود. این مقادیر برای Demo هستند و نباید در Build Production استفاده شوند.

## محیط ایجادشده و بررسی‌شده — 2026-11-07

Demo مستقل روی سرور ایجاد و Seed کامل اجرا شد؛ ۳۱ حساب و ۴۰ فایل/درخواست اولیه دارد. سناریوهای E2E، رکوردهای مصنوعی بیشتری در همین Demo ایجاد کرده‌اند. هیچ داده واقعی Production کپی نشده است.

با تونل SSH فعال همین دستگاه:

- لندینگ: http://demo.localhost:4201
- پنل: http://demo.localhost:4200
- API: http://demo.localhost:8102

حساب‌های نمونه: سوپرادمین `09000100001`، دفتر `09000100010`، کارشناس `09000100030`، کاربر `09000100060`. رمز همه حساب‌های Seed طبق درخواست مالک `123456789` است. این رمز برای حساب واقعی Production اعمال نشده است. سرویس‌ها روی loopback هستند و این نام‌های localhost برای دسترسی عمومی اینترنتی نیستند. Chrome نام demo.localhost را به loopback resolve می‌کند.
