# لندینگ در مخزن کامل ملکینو

منبع لندینگ در پوشه `landing/` مخزن `https://github.com/Asajadafsar/mlkino` قرار دارد؛ پنل در `frontend/` و بک‌اند در ریشه همین مخزن است.

در همین پوشه `npm ci` و `npm run dev` را اجرا کنید تا لندینگ روی http://localhost:3001 بالا بیاید. از ریشه مخزن، پنل با `npm --prefix frontend start` روی پورت 3000 و API با `python3 manage.py runserver 127.0.0.1:8000` اجرا می‌شوند. برای اشتراک کوکی لوکال، نام میزبان یکسان localhost را در مرورگر استفاده کنید.

در Production، متغیرهای زمان build برابر `NEXT_PUBLIC_PANEL_URL=https://panel.mlkino.com` و `NEXT_PUBLIC_API_URL=https://api.mlkino.com` هستند. مقدارها عمومی‌اند؛ هیچ Secret یا token در متغیر NEXT_PUBLIC قرار ندهید. تغییر این مقدارها نیازمند build مجدد است.

لندینگ مهمان را عمومی نمایش می‌دهد. دکمه حساب مهمان به لاگین پنل می‌رود؛ حساب واردشده نام و نقش واقعی و لینک پیشخوان دارد. وضعیت ورود از endpoint محدود `/accounts/session/` با credentials گرفته می‌شود. کوکی‌ها HttpOnly و روی میزبان API باقی می‌مانند؛ اطلاعات ورود در query یا localStorage منتقل نمی‌شوند. مبدأهای دقیق لندینگ و پنل در CORS و کنترل درخواست‌های تغییردهنده API مجاز شده‌اند.

ثبت ملک، درخواست، گفتگو و سایر عملیات خصوصی در پنل انجام می‌شوند. مقصد داخلی `next` در ورود/ثبت‌نام حفظ می‌شود؛ مقصد خارجی یا مسیر حلقه ورود رد می‌شود. داده‌های نمونه عمومی لندینگ، داده خصوصی کاربران نیستند.

لندینگ Production روی https://mlkino.com مستقر است. [گزارش تست، امنیت و بازگشت](../../docs/public-deployment-20261105.md) در مستندات مخزن کامل قرار دارد.
