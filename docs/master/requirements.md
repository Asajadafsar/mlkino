# بخش ۳ — رفع فوری مشکلات فعلی

## 3.1 رفع خطاهای 404

در بخش‌های مختلف پلتفرم خطای زیر رخ می‌دهد:

`Request failed with status code 404`

تمام APIهای استفاده‌شده در فرانت‌اند را بررسی کن.

موارد زیر باید بررسی شوند:

- اشتباه بودن Endpoint
- تفاوت مسیرهای فرانت‌اند و بک‌اند
- Prefix اشتباه
- Trailing Slash
- API Base URL
- Dynamic Route
- Missing ViewSet
- Missing URL Registration
- خطاهای Reverse Proxy
- مسیرهای حذف‌شده
- اختلاف نسخه فرانت‌اند و بک‌اند

برای هر خطا علت واقعی را پیدا و اصلاح کن.

از Catch کردن خطا و مخفی کردن آن به‌جای رفع مشکل خودداری کن.

## 3.2 رفع مشکل انگلیسی شدن ناگهانی پنل

هنگام بارگذاری، پنل گاهی به زبان انگلیسی تغییر می‌کند و متن `undefined` نمایش داده می‌شود.

باید ریشه مشکل بررسی شود:

- Hydration Mismatch
- SSR / CSR Differences
- Missing Translation Keys
- Undefined API Responses
- Invalid Initial State
- Race Conditions
- Auth Loading State
- Missing User Profile
- Locale Initialization
- Browser Storage
- React Rendering Errors

### نتیجه مورد انتظار

- رابط همیشه فارسی باشد.
- جهت همیشه RTL باشد.
- هیچ متن undefined نمایش داده نشود.
- تغییر ناگهانی زبان هنگام Load رخ ندهد.
- Skeleton مناسب هنگام دریافت اطلاعات نمایش داده شود.
- وضعیت ورود کاربر بدون پرش UI مشخص شود.
- خطاهای React و Console بررسی و رفع شوند.

# بخش ۲۷ — شیوه اجرای مأموریت

این درخواست یک مأموریت جامع است.

**تمام بخش‌ها را در یک برنامه اجرایی واحد انجام بده و هیچ بخشی را صرفاً به دلیل طولانی بودن Scope حذف نکن.**

با این حال، اجرای فنی باید مرحله‌بندی‌شده باشد تا کیفیت، امنیت و قابلیت بازگشت حفظ شود.

### روش اجرا

1. بررسی واقعی پروژه
2. تهیه Master Checklist
3. شناسایی وابستگی‌ها
4. طراحی تغییرات دیتابیس
5. اصلاح مشکلات بحرانی
6. توسعه Backend
7. توسعه Frontend

9. بازطراحی UI/UX

11. تست

13. آماده‌سازی انتشار
14. دریافت تأیید برای Deploy
15. انتشار

در هر مرحله وضعیت موارد را مشخص کن:

اگر موردی به دسترسی، سرویس خارجی، تصمیم تجاری یا تأیید نیاز داشت، آن را شفاف اعلام کن و سایر کارهای مستقل را ادامه بده.

### گزارش نهایی

در پایان باید ارائه شود:

- فایل‌های تغییرکرده
- مدل‌های ایجادشده یا اصلاح‌شده
- Migrationها
- APIهای جدید
- صفحات جدید
- قابلیت‌های تکمیل‌شده
- مشکلات رفع‌شده
- تست‌های اجراشده و نتایج آن‌ها
- نتیجه بهینه‌سازی سرعت
- وضعیت Push
- وضعیت Deploy
- وضعیت Seed نمایشی
- مشکلات باقی‌مانده
- موارد نیازمند تأیید

**هیچ قابلیتی را بدون پیاده‌سازی و تست واقعی Completed اعلام نکن.**

**هیچ موفقیت در Push، Deploy، Migration یا Seed را بدون مشاهده نتیجه واقعی ادعا نکن.**

هدف نهایی، تحویل یک پلتفرم مدیریت املاک یکپارچه، حرفه‌ای، سریع، امن، قابل توسعه و آماده استفاده واقعی است.

شروع کن: ابتدا ساختار واقعی پروژه را بررسی کن، سپس Master Checklist را ایجاد کن و تمام فازها را طبق وابستگی‌های فنی پیش ببر.
