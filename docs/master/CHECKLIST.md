## معماری موجود (بررسی‌شده)

- Django apps: accounts (حساب، پروفایل، نشست، اعلان، ممیزی) و panel (املاک JSON موجود PropertyRecord، قرارداد/پیگیری EstateActivity، چت/تیکت، وظایف، جغرافیا، تنظیمات و RBAC).
- پنل React 18 / CRA / TypeScript، لندینگ Next.js 16.4.5 / React 19، PostgreSQL در Production، JWT کوکی HttpOnly و Channels/Redis.
- داده ملک و قرارداد تکرار نمی‌شوند؛ گردش‌کار جدید به مدل‌های موجود متصل می‌شود. مدل‌های مکمل فقط برای ارجاع، CRM، زمان‌بندی بازدید، علاقه‌مندی و دفتر مالی لازم‌اند.
- انتشار فعلی: Nginx + Gunicorn/ASGI + Node standalone؛ تاریخچه migrations سرور panel با لوکال متفاوت است و در packaging باید حفظ شود.

## ترتیب اجرا

1. مدل‌های افزایشی و سیاست دسترسی؛ موتور ارجاع و تراکنش مالی.
2. API عمومی با whitelist و انتشار صریح؛ علاقه‌مندی، بازدید و چت مرتبط با ملک.
3. UIهای پنل و لندینگ واقعی، تکمیل تنظیمات و گزارش‌ها.
4. تصاویر امن، رفع locale/404، آزمون‌های واحد/API/مرورگر و اندازه‌گیری.
5. Demo مستقل سرور با محافظ محیطی و داده مصنوعی؛ پذیرش، بسته انتشار، بکاپ و تأیید انتشار جدید مطابق سند.
