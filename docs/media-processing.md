# پردازش تصویر و حفاظت از مدارک

`accounts.media_processing` تصاویر Raster را از روی محتوای واقعی، MIME، حجم و ابعاد اعتبارسنجی می‌کند. سقف بارگذاری تصویر ۵ MiB، سقف پیکسل ۲۴ میلیون و سقف ضلع ۱۲۰۰۰ است. SVG/فایل فعال، فایل خراب، MIME جعلی و تصویر متحرک در این مسیر پذیرفته نمی‌شوند. چرخش EXIF اصلاح می‌شود؛ GPS، EXIF، ICC، توضیحات و metadata غیرضروری به فایل خروجی منتقل نمی‌شوند. شفافیت PNG حفظ می‌شود.

- آواتار جدید: WebP، حداکثر ضلع ۵۱۲، نام UUID بدون شماره تلفن در مسیر.
- تصاویر ملک: WebP در اندازه‌های متناسب ۳۲۰، ۷۶۸ و ۱۶۰۰؛ تصویر کوچک بزرگ‌نمایی نمی‌شود.
- خروجی `image_variants`: برای هر URL اصلی، URL، عرض، ارتفاع، MIME و تعداد بایت اندازه‌های مختلف را نگه می‌دارد.
- AVIF اختیاری فقط در صورت پشتیبانی Encoder و درخواست صریح helper تولید می‌شود؛ WebP مسیر پیش‌فرض است.
- تصویر برند/اشتراک‌گذاری تنظیمات نیز از پیکسل پاک‌سازی و WebP می‌شود. ICO معتبر favicon در قالب مناسب خودش حفظ می‌شود. فایل‌های SVG ثابت و برداری موجود تغییر نکرده‌اند.

برای فایل‌های قدیمی، دستور زیر پیش‌فرض فقط بررسی انجام می‌دهد:

```sh
python manage.py optimize_property_images --max-records=100 --batch-size=25
# فقط پس از بررسی خروجی و روی محیط مورد تأیید:
python manage.py optimize_property_images --apply --after-id=0 --max-records=100
```

هیچ URL دلخواه از اینترنت دانلود نمی‌شود؛ فقط فایل موجود در storage خود سامانه بررسی می‌شود. فایل اصلی حذف یا بازنویسی نمی‌شود، بنابراین URLهای قدیمی تصاویر ملک معتبر می‌مانند. به‌روزرسانی JSON با قفل رکورد و مقایسه فهرست تصاویر پیش از نوشتن انجام می‌شود؛ تغییر هم‌زمان کاربر بازنویسی نمی‌شود. اجرا محدود و تکرارپذیر است.

## مدارک خصوصی

تصویر کارت ملی، پروانه دفتر و مدرک کارشناس از endpoint زیر تحویل داده می‌شوند:

`GET /accounts/documents/<user_id>/<national-card|agency-license|expert-document>/`

دسترسی فقط برای خود فرد، سوپرادمین یا دفتر مرتبط با همان کارشناس است. پاسخ دانلود attachment، `private, no-store`، `nosniff` و CSP sandbox دارد. شناسه نامرتبط/ناموجود ۴۰۴ و کاربر مهمان ۴۰۱ می‌گیرد. serializer هیچ URL مستقیم media برای این مدارک برنمی‌گرداند. تصویر مدارک نیز بازکدگذاری می‌شود؛ PDF کامل و محدود به ۱۰ MiB تنها برای مدرک فایل مجاز است، محتوای فعال/پیوست/رمزگذاری شناخته‌شده رد می‌شود و همیشه به‌صورت attachment تحویل داده می‌شود. این بررسی جایگزین اسکن آنتی‌ویروس فایل‌های دریافت‌شده نیست.

**هنگام انتشار، قواعد Nginx برای تمام مسیرهای قبلی `identity/`، `agencies/licenses/` و `experts/documents/` زیر `/media/` باید هم‌زمان مسدود شوند.** تغییر serializer به‌تنهایی لینک‌های قدیمی ذخیره‌شده را خصوصی نمی‌کند. اسکریپت `deployment/configure-nginx.py` قواعد جدید را حتی در صورت وجود بلوک قدیمی private_chat اضافه می‌کند. فایل واقعی مدارک حذف نمی‌شود.

## اندازه‌گیری واقعی دارایی‌های ثابت

۱۰ تصویر PNG متعلق به پروژه در پنل به WebP تبدیل و ارجاعات آن‌ها به نسخه جدید متصل شدند؛ فایل‌های PNG اصلی حفظ شده‌اند. مجموع فایل‌های مورد اندازه‌گیری از ۱۵٬۵۷۸٬۳۹۵ به ۱٬۱۸۹٬۴۱۸ بایت کاهش یافت (حدود ۹۲٫۴٪). جزئیات اندازه‌ها در `docs/reports/static-image-optimization.json` است. این نتیجه، اندازه فایل است و ادعای Lighthouse یا LCP اندازه‌گیری‌نشده نیست.

۲۰ تست مشترک تصویر/مدرک/تنظیمات/مجوز کاربر پاس شدند؛ شامل MIME جعلی، SVG، ابعاد بیش‌ازحد، تصویر ناقص، حذف metadata، چرخش، alpha، responsive sizes، پاک‌سازی ذخیره ناقص، جلوگیری از SSRF/فرار از storage، IDOR و تبدیل تدریجی تکرارپذیر با حفظ فایل قدیمی.
